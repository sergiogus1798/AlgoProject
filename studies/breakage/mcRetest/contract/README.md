# retest/contract — the result read as the contract's blocks

`run.one()` returns numbers; this folder turns them into the result the window paints and the
batch page draws. It decides nothing — `verdict/` does — and computes nothing but the reshaping.

| file | what it does | run it | in → out |
|---|---|---|---|
| `__init__.py` | The Monte Carlo Retest result read as the contract's blocks. | — | — |
| `criteria.py` | The retest's criteria metrics — the original among its own re-runs — as a table and as columns. | imported | result → table, columns |
| `retention.py` | The fragility tab: T1 as one small table, whose cells are the judge's facts. | imported | result + T1 rows → tab |
| `tabs.py` | One strategy's retest as the contract's tabs: the call, what breaks it, the stress, the eight. | imported | result → tabs |
| `words.py` | The Spanish sentence behind every check that can fire, and every task. gates decides, this narrates. | imported | codes → text |

`report.py` refuses to start when `gates.VETOES` and `words.SENTENCES` name different vetoes: a
veto that fires with no sentence is a verdict nobody can argue with.
