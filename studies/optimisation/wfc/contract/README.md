# wfc/contract — the correlation as the contract's blocks

Nothing here computes: `measure/` and `verdict/` did. It turns their numbers into the result the
window paints and `core/study/render` draws into the batch's `estudios/` folder.

| file | what it does | run it | in → out |
|---|---|---|---|
| `__init__.py` | Names what the package is; holds no code | — | — |
| `wfc.py` | The WFC: every partition the ledger's door offers, each as its own scatter and correlation table under one selector (feedback §8.2, 2026-09-30), the strata a point can belong to, and the glossary that says the PBO does not move with the composition | imported | kept points per partition → tab |
