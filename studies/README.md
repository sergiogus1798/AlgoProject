# studies — every question asked of a strategy or a population

One folder per study, grouped by the WORKFLOW step it serves. How a study module is laid out, where
its results land and the traps that already produced wrong answers: `CLAUDE.md` here.

| folder | the question | steps |
|---|---|---|
| `screening/` | of thousands, which deserve to go on? | 7–8 |
| `transfer/` | does the edge work away from where it was built? | 9–12 |
| `breakage/` | had the world been slightly different, what breaks it? | 13–16 |
| `optimisation/` | does optimising buy anything, or is choosing parameters overfitting? | 16.5–19 |
| `closing/` | the final call, the shape of the edge, and the stop it trades with | 20–21, 24 |
| `readings/` | what one strategy's result is made of | 8, 22, 23, 25 |
| `data/` | whether the inputs are fit to judge with: `feedQuality` (encargo 17), `spread` | 4, 8 |
| `research/` | where to look next, before any idea exists: the market profile, what was tried, the literature (`research/README.md`) | 1 |
| `run/` | where a study's input lives on the data root, found before a run is offered (`run/README.md`) | — |
