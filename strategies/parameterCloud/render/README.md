# parameterCloud/render — how all of that is read

| file | what it does | in → out |
|---|---|---|
| `text.py` | Every reading as a table, in the order the argument is made | numbers, readings → text |

Computes nothing. The collapsed parameters print **first**, before any index, because a parameter
the filters flattened is a finding about the strategy and not a footnote about the data.
