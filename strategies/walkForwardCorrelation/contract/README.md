# walkForwardCorrelation/contract — the two readings as the contract's blocks

Nothing here computes: `measure/` and `verdict/` did. It turns their numbers into the result the
window paints and `core/study/render` draws into the batch's `estudios/` folder.

| file | what it does | run it | in → out |
|---|---|---|---|
| `__init__.py` | Names what the package is; holds no code | — | — |
| `wfc.py` | The WFC: its call, the cloud of tuples with the fit, the correlation and the ends of the in-sample ranking | imported | kept points → tab |
| `cscv.py` | The CSCV: the head rule's PBO as the call, λ per rule with the median marked, the rules side by side, and the head rule partition by partition | imported | runs → tabs |
