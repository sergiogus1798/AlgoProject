# docs — manual, dossiers and generated maps

The Spanish-language documents here are written for the project owner and for agents given Spanish
briefs; they stay in Spanish. Code-facing documentation is in each folder's `README.md` and in
`../knowhow/`.

| path | what it is |
|---|---|
| `manual/` | The owner's manual: twelve PDFs, one per workflow family (`01-empezar.pdf` … `12-en-real.pdf`). Spanish. Built by `tools/manual.py` from chapters kept in the data root |
| `AgentPDFs/` | Dossiers and decision papers (Markdown, many with a PDF). Spanish. `WORKFLOW.md` is the single ordering of the 26 workflow steps, from idea to surviving strategy, with the state of each; it overrides the other dossiers |
| `encargos/` | Self-contained briefs for agents (25 files, numbered). Spanish |
| `DEPENDENCIES.md` | Import map of the Python code. Generated by `tools/depmap.py` (also nightly); `tools/checks.py` fails when stale. English |
| `SKILLS.md` | Which agent skills exist, what each is for, which could retire. Tables generated by `tools/skillmap.py`; the judgement above them is hand-written. Spanish |
| `OPEN-closed.md` | Archive of closed issues moved verbatim out of the root `OPEN.md`, numbers kept. English |
| `MAPA-DE-CARPETAS.md` | Where old paths went after the 2026-09-25 reorganisation (`strategies/`, `tasks/`, `nulls/`, `gate/`). Spanish |
| `SETUP-NEW-MACHINE.md` | Step-by-step setup of the project and its SQX installs on a new machine, with a check per step. English |

Open problems and pending decisions: `../OPEN.md`.
